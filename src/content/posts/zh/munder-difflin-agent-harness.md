Munder Difflin 是一个开源的本地多智能体编排工具，今天登上 GitHub Trending 榜首。名字致敬《办公室》里的纸业公司，产品形态也照搬了办公室：团队的每个成员都拥有一个跑在自己电脑上的克隆智能体，它们 24 小时接力工作、互相发消息、评审彼此的 PR，需要人类拍板时才升级上报。

它的设计有几个值得注意的点。其一，工具不训练也不托管模型，而是包裹你已经订阅的 12 种 CLI 智能体——Claude Code、Codex、Grok、Kimi Code 等，用现有订阅的额度上限运行，本地优先，代码和密钥不离开机器。其二，「办公室」主题的模拟是确定性的、不消耗 token，主要作为监控界面；克隆体之间的通信端到端加密。其三，每个智能体运行在独立 worktree 中，通过共享记忆（MemPalace）继承你的工作方式，形成团队级上下文。

HN 社区的热议点很有意思：很多人指出《办公室》的荒诞恰好精准映射了当下智能体集群的通病——各自追求局部目标、互相竞争，最终导致整体结果莫名崩坏。与其说这是玩具，不如说它把「多智能体协调」这个 Agent Economy 的核心问题，用讽刺的形式摆到了桌面上。
