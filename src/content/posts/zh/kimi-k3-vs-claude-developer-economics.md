开发者 Stephen Bochinski 在博客中分享了他对 Kimi K3 和 Claude 的真实使用对比，结论直白：「我分辨不出区别」。无论是回答质量、输出 token 数量还是任务完成方式，K3 与 Claude 在编码场景下几乎一致。

真正拉开差距的是价格。K3 API 每百万输入 token 仅 $3，输出 $15；而 Claude 的高端模型对应为 $10 和 $50。订阅侧差距更悬殊：Kimi 付费计划起价 $19/月，$39 的编码档位比 Claude 任何同等价位的计划都慷慨得多——Claude 的 $20 计划计量严格，一个正常工作日就能消耗完额度。

更关键的是美国 AI 出口管制带来的意外后果。Bochinski 指出，Claude 的 Fable 5 因政策限制无法持续提供给 $20 计划用户，计划无声降级为 Opus。而 Kimi K3 和 GLM 5.2 等中国开源模型没有任何使用限制。他的判断是：「限制美国模型唯一的真实效果是限制美国客户自己。」当开放权重的中国模型以更有竞争力的价格提供无限制的能力时，开发者的选择方向已经非常明确。
