Anthropic 宣布，把 Agent Skills 这一开放标准捐给 Linux 基金会旗下的 Agentic AI Foundation（AAIF）。Agent Skills 用来给 AI 智能体注入专门的知识和工作流：一个 skill 就是一个文件夹，里面有教智能体完成特定任务的 `SKILL.md`，以及它需要的脚本和参考材料。Anthropic 说，标准自 2025 年 12 月公开以来，已经有超过 70 个智能体平台接入，其中包括 ChatGPT、Cursor、GitHub Copilot 和 VS Code；迄今发布了约 100 万个 skills，安装次数接近 2.8 亿。

这笔捐赠覆盖 Agent Skills 的名称和徽标、GitHub 组织，以及 agentskills.io 域名。Anthropic 强调，不加入 AAIF 也可以继续使用或贡献这个标准。AAIF 是 Anthropic 去年与 Block、OpenAI 共同发起的，MCP（Model Context Protocol）此前也捐在这里。标准的维护将由 Anthropic、谷歌、OpenAI 等公司的工程师以个人身份进行，David Soria Parra 和 Mahesh Murag 担任 Lead Maintainers。Anthropic 还提出了一份起步路线图，涵盖版本化发布、正式提案流程，以及给编写和安装 skills 的人用的安全指引。

同日，AAIF 在 AGNTCon + MCPCon North America 上宣布一并收下另外三个项目：OpenAI 贡献的 Open Responses（跨模型提供商的 LLM 接口规范）、Hugging Face 贡献的 OpenEnv（面向强化学习的可互操作训练环境），以及阿里贡献的 OpenSandbox（面向 AI 应用的通用沙箱平台）。AAIF 称，加上今天这四个，旗下托管项目从 2025 年 12 月成立时的 3 个扩到了 10 个。

Agent Skills 最初是 Anthropic 做 Claude Code 时长出来的：通用知识工作做得不错，但缺真实业务任务需要的程序性知识。2025 年 10 月上线几周内，开发者就在 GitHub 上发布了数千个 skills，还为 Codex、Cursor、OpenCode 写了加载器；随后 Anthropic 把它做成独立的开放标准。现在把名称、组织和域名都交到基金会手里，等于把智能体互操作从"实验室开源"推进到了"基金会治理的公共层"。
