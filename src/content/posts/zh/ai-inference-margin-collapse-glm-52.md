GLM-5.2 是智谱 AI 发布的开源模型，744B 参数（40B 活跃），在多项基准测试中与 Claude Opus 和 GPT-5.5 不相上下。但真正撼动行业的不只是模型本身，而是它所代表的成本结构变化。

分析师 Martin Alderson 在深度分析中指出，GLM-5.2 的推理价格约 $4.40/百万 token，不到 Claude Opus（约 $25/百万 token）的 20%。更关键的是，Z.ai 和 Fireworks 等推理提供商提供了完全兼容 OpenAI 和 Anthropic 的 API 接口——只需修改 base URL 和 API key，原本使用 Claude Code 的智能体工作流就能无缝迁移到 GLM-5.2，切换成本几乎为零。

Alderson 认为，当前前沿实验室的推理定价包含约 90% 的毛利润率（基于算力成本），这一结构正面临开源模型的根本性挑战。当开源模型性能逼近闭源、成本仅为五分之一、迁移零摩擦时，整个 AI 推理的商业逻辑将被重塑。

GLM-5.2 并非没有短板——缺乏视觉能力、Web 搜索支持薄弱、推理速度偏慢。但对于后台智能体任务（代码审查、批处理工作流），这些限制并非致命。OpenAI 和 Anthropic 的护城河正从"技术领先"滑向"用户体验和生态整合"。如果推理利润率真的崩塌，谁将受益、谁将受损？这或许是 2026 年下半年 AI 行业最重要的商业问题。
