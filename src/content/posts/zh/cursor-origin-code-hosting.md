Cursor 从 AI 编辑器正式切入代码托管。8 月 17 日发布的 Origin 以早期 beta 形式向所有付费用户开放，提供仓库、拉取请求、代码浏览和 GitHub 双向同步等基础能力，官方称其"为智能体规模设计"，更多智能体原生功能即将上线。

Origin 的核心卖点是让代码、PR 与智能体同处一处：浏览代码时可以直接让 Cursor 回答问题、修改代码、更新 PR 或推送分支；同步的 GitHub 仓库评论双向互通，PR 预览部署通过 Vercel、Depot、Buildkite 等应用扩展接入。

这一动作的潜台词很直接——代码托管的入口价值正在被 AI 编程工具重新定价。GitHub 靠 Copilot 守住生态，Cursor 则选择自建基础设施，把仓库、PR 与智能体工作流绑定在自己的平台上。考虑到 Cursor 已被 SpaceX 收购，这场竞争也带上了 Musk 与微软直接对抗的色彩。对开发者而言，多一个"智能体原生"的托管选项，意味着工作流默认绑定 GitHub 的时代正在松动。
