OpenAI 昨天（7月9日）正式发布了 **ChatGPT Work**——ChatGPT 中一个新的 agent 模式。它不再只是"回答问题"，而是接受一个目标，跨应用收集上下文、自主拆解步骤、持续工作数小时，最终交付一份完整的成品。

这跟已有的 Workspace Agents（团队级可复用智能体）是不同定位：ChatGPT Work 是**面向个人的深度工作 agent**，更像是帮用户"做完一件事"而不是"协助一个流程"。

### 核心能力

ChatGPT Work 基于 **Codex** 构建，能够在云端持续运行。它可以从用户连接的 Google Drive、Microsoft 365、Slack 等应用中拉取上下文，然后生成文档、电子表格、演示文稿、报告甚至可直接部署的网页应用。OpenAI 的描述是"给它一个目标，剩下的交给它"。

它支持三个 GPT-5.6 模型版本——**Sol**（最强）、**Terra**（均衡）、**Luna**（轻量快速），用户可根据任务复杂度和对耗时的容忍度选择。同时支持从低到多个等级的 **reasoning effort**（推理努力级别），让用户在速度与深度之间做取舍。

### 与 GPT-5.6 同日发布

ChatGPT Work 不是孤立产品——它的底层模型能力来自 GPT-5.6 系列。Sol 的 AI 综合评分（~59，Artificial Analysis）略超 Claude Fable 5，而 Terra 在同档定位上与 Fable 5 互有胜负。配合 ChatGpt Work 的 agent 层，GPT-5.6 实际能做的事远比模型本身更值得关注。

### 一句话判断

如果说 GPT-5.6 是更好的引擎，那 ChatGPT Work 就是 OpenAI 终于把它装进了一台完整的车子。它标志着 ChatGPT 的产品定位从"更好的聊天工具"转向"能替你做完工作的 agent"，而这个转变可能比模型本身的能力提升更能定义 OpenAI 的下一个阶段。
