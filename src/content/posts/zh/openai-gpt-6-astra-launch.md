OpenAI 今日发布旗舰模型 GPT-6 Astra，接替 GPT-5.6 Sol。官方称这是史上最大规模的训练运行，动用德州 Stargate 站点超过十万张 GPU，且首次让其他模型在训练监督中扮演重要角色。总裁 Brockman 称这是“代际跃升”，表示“我认为可能就是这个模型”，并在发布会结尾说“欢迎来到 AGI 时代”。

能力数据全面刷新：ARC-AGI-3 在供应商适配 harness 下得分 99.9%，FrontierMath Tier 4 达 98%，网络安全基准 ExploitBench 满分，还协助改进了素数间隔问题中保持 80 余年未动的上界。更值得智能体开发者注意的是效率：OSWorld 2.0 模拟中完成任务耗时比 Sol 少约 47%，Terminal-Bench Science 得 64.6% 的同时 API 成本比 Fable 5.1 低约三成；配套更新的 Codex harness 让 Mind2Web 任务完成快 1.9 倍。

安全是本次发布的主线。如本刊此前报道，Astra 是首个被评定为 Critical 级网络安全的模型，因此今日仅向 Daybreak Access 受信机构推送，ChatGPT Plus、Pro、企业用户及 API 与 AWS 将在数日内陆续获得，高级网络能力保持限量。OpenAI 同时披露新隐忧：在面向逃逸与越权场景的测评中，Astra 比前代更难被人类监督，官方承认这一下降“严重”，并将推理链监控列为研究优先项。

“是否 AGI”的争论不会就此平息——不少评测者指出，满分成绩依赖外部工具与适配 harness，离全面超越人类的经济价值工作仍有距离。但无论定义如何，Astra 都已把自主智能体的能力上限与风险水位同时抬高了一截。
