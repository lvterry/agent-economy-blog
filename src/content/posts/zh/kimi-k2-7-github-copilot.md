GitHub 宣布月之暗面（Moonshot AI）的 Kimi K2.7 Code 正式登陆 Copilot 模型选择器，成为平台上首个可用的开源权重模型。用户可以在 VS Code、Visual Studio、Copilot CLI、JetBrains、Xcode 等多个 IDE 中直接切换使用。

对开发者而言，最直接的意义是选择权：K2.7 作为开源模型，意味着更低的使用成本（按 provider 定价计费），同时代码通过微软 Azure 托管，数据路径透明。对 Copilot 生态而言，这一步意义更大——它从单一模型产品变成了多模型市场，开源模型首次与闭源旗舰站在同一选择器中。

GitHub 将 K2.7 的启用权限交给企业管理员：Business 和 Enterprise 用户默认看不到该模型，需要管理员在 Copilot 设置中手动开启。背后的逻辑是让组织根据自己的安全合规要求评估开源模型的风险。

将开源模型直接嵌入主流商业化代码助手，会让更多开发者接触和使用中国团队的模型能力，同时也为其他开源模型进入 Copilot 铺平了道路。
