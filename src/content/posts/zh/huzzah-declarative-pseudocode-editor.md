今年年初编码智能体刚变得好用那阵，Daniel Vaughn 和许多工程师一样兴奋，但几个月后他「彻底倦怠了」。问题不在代码质量，而在于交互方式：用长段英文向聊天框描述每次修改，指令重复、消耗 token，且提示词用完即弃——代码里再也找不到人类意图的可靠记录。

他的实验性编辑器 Huzzah 给出了另一种范式：把提示词写成伪代码文件，声明式而非命令式，持久保存而非转瞬即逝。你在 `.hz` 文件里写下类似 `loop 100 / modulo 3 ? "fizz"` 的描述，保存后 LLM 自动生成真实代码；要改需求就改文件，Huzzah 捕捉 diff 并据此重新生成受影响的部分。伪代码同时充当开发者文档，甚至可跨语言复用。

这个方向值得关注，因为它触及智能体工具链的一个核心问题：人类与机器之间的「意图」如何被记录和迭代。聊天式 agent 把思考过程外包给模型，而 Huzzah 试图把意图沉淀为可审阅、可版本化的资产。当然它还只是实验品，作者也承认在大规模、既有代码库上未必适用——但「提示词即代码」的思路，很可能是编码智能体下一阶段的分岔路口。
